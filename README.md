# Alex Studio

## النطاق المعتمد

Alex Studio أداة تطوير شخصية محلية لمستخدم واحد، تعمل على **Android فقط**. ليست خدمة عامة أو منصة متعددة المستخدمين، ولا تتطلب نظام حسابات أو أدوار أو إدارة مستخدمين.

## الأقسام المعتمدة — لا تُضاف أقسام خارجها

1. إدارة المشاريع: إنشاء المشاريع وعرضها وتعديلها وحذفها.
2. إدارة الملفات: إنشاء الملفات وقراءتها وتعديلها وحذفها.
3. توليد AI: تحويل الفكرة أو المواصفات إلى خطة ومسودة ملفات مترابطة.
4. التخطيط والمراجعة: عرض الخطة والملفات والفروقات قبل التطبيق.
5. Apply: تطبيق المسودة بعد موافقة المستخدم الصريحة.
6. Build وPreview: بناء المشروع وتشغيل معاينته.
7. Diagnose & Repair: تشخيص الأخطاء وإصلاحها وإعادة الاختبار.
8. Rollback والتسليم: استرجاع التغييرات عند الفشل وتسليم المشروع.

## دورة العمل

**فهم ← تخطيط ← توليد ← مراجعة ← موافقة ← تطبيق ← اختبار ← تشخيص ← إصلاح ← إعادة اختبار ← تسليم.**

الموافقة على الخطة لا تعني الموافقة على تطبيق الملفات. لا يحدث Apply إلا بموافقة صريحة منفصلة.

## حدود المشروع

- Android هو منصة المنتج الوحيدة.
- التشغيل محلي وشخصي؛ لا استضافة عامة ولا خدمة SaaS.
- لا تسجيل مستخدمين متعددين، ولا أدوار، ولا صلاحيات مؤسساتية، ولا متطلبات امتثال لخدمة عامة.
- لا دعم Windows أو Linux كمنصات منتج.
- بيئة التطوير أو CI لا تغيّر منصة المنتج المستهدفة.
- يُحتفظ فقط بفحوص سلامة بسيطة تمنع الخروج من مجلد المشروع أو فقدان الملفات بالخطأ، وبالنسخ الاحتياطي والتراجع.
- لا تُضاف ميزات أو أقسام خارج القائمة الثمانية دون قرار جديد صريح من مالك المشروع.

## الحالة الحالية المعروفة

| الوظيفة | الحالة |
|---|---|
| واجهة الاستوديو وصفحات المشاريع والمحرر والمعاينة | موجودة؛ تحتاج قبولاً نهائياً على Android |
| قراءة ملفات المشاريع | موجودة |
| إنشاء المشاريع | معطّل حالياً في الفرع الأساسي الذي بدأ منه التنظيف |
| كتابة الملفات وحذفها | معطّلة حالياً في ذلك الفرع |
| تطبيق دفعات AI | متوقف حالياً قبل مرحلة الكتابة |
| تشغيل أوامر Build وPreview | غير مكتمل؛ المنفذ الحالي يعيد UNAVAILABLE |
| دورة AI الكاملة | غير مثبتة |
| قبول Android الفعلي | لم يُنفذ بعد |

هذه الحالة وصف لما كان موجوداً قبل إكمال التنظيف، وليست ادعاءً بأن الوظائف المعطلة قد أُصلحت.

## طريقة العمل على المستودع

- التغييرات على فرع مستقل، وليس مباشرة على main.
- لا يُعلن نجاح أي وظيفة إلا بنتيجة اختبار فعلية.
- لا تُعاد فحوص قسم أُغلق بنجاح إلا إذا تغيّر الكود المرتبط به.
