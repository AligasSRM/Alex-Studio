# Alex Studio

Alex Studio أداة تطوير شخصية محلية لمستخدم واحد على **Android فقط**.

## الأقسام المعتمدة

1. إدارة المشاريع: إنشاء، عرض، تعديل، حذف.
2. إدارة الملفات: إنشاء، قراءة، تعديل، حذف.
3. توليد المشاريع بالذكاء الاصطناعي.
4. التخطيط ومراجعة الملفات والفروقات.
5. تطبيق التعديلات بعد موافقة صريحة.
6. بناء المشروع ومعاينته.
7. تشخيص الأخطاء وإصلاحها وإعادة الاختبار.
8. التراجع والتسليم.

لا توجد منصة عامة أو مستخدمون متعددون أو أدوار. لا دعم Windows أو Linux كمنصات للمنتج. لا تُضاف أقسام خارج القائمة.

## دورة الاستخدام

فهم الطلب ← تخطيط وتوليد ← مراجعة ← موافقة منفصلة على التطبيق ← تطبيق ← بناء واختبار ← إصلاح ← إعادة اختبار ← تسليم.

## الحالة الحالية

- واجهة الاستوديو والمحرر وصفحات المشاريع والمعاينة موجودة.
- مسارات إنشاء المشاريع وتعديلها وحذفها أُعيد تفعيلها في فرع العمل؛ لم يُثبت نجاحها بعد بالاختبارات.
- مسارات إدارة الملفات وApply أُعيد تفعيلها؛ لم يُثبت نجاحها بعد بالاختبارات.
- توليد AI موجود، لكن دورة العمل الكاملة غير مقبولة بعد.
- مشغّل أوامر المشروع المحلي غير مكتمل.
- Build وPreview الفعليان غير مكتملين.
- القبول على جهاز Android فعلي لم يُنفذ بعد.

## التشغيل والتطوير

راجع [إعداد الذكاء الاصطناعي والتشغيل المحلي](docs/local-ai-setup.md).

أوامر التحقق:
- `npm test`
- `npm run typecheck`
- `npm run lint`
- `npm run build`
- `npm run test:e2e`

لا يُعلن اكتمال أي وظيفة قبل نجاح اختبارها الفعلي.
